## How to add your own files

1. Drop your file into the `files/` folder in this repo.
2. Add a line above pointing to it, like:
   ```
   - [My File Name](/files/my-file.zip)
   ```
3. Commit and push — GitHub Pages rebuilds the site automatically.

> Tip: for anything version-controlled (like software releases), consider using [GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github) instead — it gives you changelogs, version numbers, and download counts for free.
